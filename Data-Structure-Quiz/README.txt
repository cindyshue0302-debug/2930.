# 資料結構與程式設計測驗網站 (陣列與串列主題) 

這是一個以 Python 進行題庫整理，並運用純前端技術 (HTML/JS) 搭配 Firebase 雲端資料庫建構的互動式線上測驗系統。

## 系統特色
- **智慧考卷生成**：具備「承上題」綁定機制，並能打亂題庫順序抽取 10 題。
- **錯題獨立補考**：系統會記錄答錯的題目，提供獨立的補考模式強化記憶。
- **弱點與強項分析**：交卷時動態生成個人知識點分析。
- **雲端排行榜**：串接 Firebase Realtime Database，達成跨設備的排行榜同步。
